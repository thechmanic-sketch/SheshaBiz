# SheshaBiz

Marketing site for **SheshaBiz** — a free Android app for South African small
businesses to create quotations, invoices, and run a point-of-sale till, all
from one phone.

This branch (`main`) holds only the website (`index.html` + `assets/`),
published via GitHub Pages.

The Android app's source code lives on the
[`claude/quickquote-sa-android-kxdu2i`](../../tree/claude/quickquote-sa-android-kxdu2i)
branch, with built APKs published under
[Releases](../../releases).
